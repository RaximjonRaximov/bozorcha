# Bozorcha qabul mezonlari

- Mahsulotlarni nom, narx, kategoriya va ishlab chiqaruvchi bilan ko‘rsatish.
- Qidiruv va kategoriya bo‘yicha filter ishlashi.
- Mahsulotni savatchaga qo‘shish, miqdorni o‘zgartirish va olib tashlash.
- Xaridor ism, telefon va manzil bilan buyurtma yuborishi.
- Backend buyurtma summasini server tomonida qayta hisoblashi.
- Admin API orqali mahsulot qo‘shish va buyurtmalarni status bo‘yicha yangilash.
- Responsive frontend va mobil savatcha.
- README, .env.example, arxitektura diagrammasi, lint va test.
