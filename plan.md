# Bozorcha rejasi

Bozorcha mahalliy ishlab chiqaruvchilar va xaridorlarni sodda katalog, savatcha va buyurtma oqimi bilan bog‘laydi. MVP mahsulotlarni ko‘rsatadi, qidirish va kategoriya bo‘yicha filterlashni beradi, savatchadan buyurtma yuboradi va admin uchun mahsulot hamda buyurtmalarni boshqarish API’larini taqdim etadi.

Arxitektura: Node.js built-in HTTP server, statik HTML/CSS/JavaScript frontend, REST API va JSON faylga doimiy saqlash. Bu tashqi servis talab qilmaydigan, tushunarli va kichik biznes uchun tez ishga tushadigan yechim.

Dizayn: mahalla bozori va zamonaviy katalog aralashmasi. Iliq krem fon ishonch beradi, yashil rang mahalliylik va harakatni bildiradi, terracotta rang narx va aksentlar uchun ishlatiladi. Layout chapda kategoriya navigatsiyasi, markazda mahsulotlar, o‘ngda savatcha paneli konsepsiyasiga quriladi.
